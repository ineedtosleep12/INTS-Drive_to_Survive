Runtime compatibility and limits
--------------------------------
- Built-in named maps: acpmf_physics, acpmf_graphics, acpmf_static. They are
  opened existing, read-only; never created by this application.
- AC and ACC reuse names. Check actual running game processes and reject
  concurrent/ambiguous AC-family games. Content Manager launcher alone is
  not an active AC driving process.
- Accept documented shared-memory families AC 1.7 and ACC 1.8, including
  patch suffixes. Do not confuse smVersion with game acVersion: a new game
  patch is not arbitrarily blocked if its shared-memory family is unchanged.
- Copy twice and compare whole prefixes. There is no documented shared
  seqlock or atomic cross-page timestamp, so perfect snapshot synchronization
  is not claimed. DistanceAgeSeconds remains unknown, not a fabricated zero.
- AC provides native track spline length. On playground/mod maps it may be
  absent; live controls still work without making up a metre scale.
- ACC marks native trackSplineLength unused. Default ACC TrackLength and
  LapDistance stay NaN. An optional verified-length provider is an explicit
  integration hook; this adapter has no guessed circuit-length table and
  does not configure or connect ACC Broadcasting.
- AC base shared memory has no authoritative current-lap-validity flag.
  ValidLapKnown remains false. ACC uses its explicit graphics isValidLap.
- Gear conversion: native 0 reverse, 1 neutral, 2 first -> -1,0,1.
- Steering is a signed normalized value. Do not label it road-wheel degrees.
- AC local velocity X is sideways, Z forwards; expose sideways magnitude
  only because the positive right-hand sign is not established here. Y yaw
  rate is native radians/sec. No directional countersteer verdict is claimed.
- ACC accG is documented global, and fuel is documented kg. Those are not
  silently mislabeled as local G or litres; corresponding fields stay NaN.
- Base pages have no handbrake input. Clutch polarity documentation differs
  across sources/builds; without live calibration the adapter leaves clutch
  pedal travel unknown instead of teaching an inverted input.
- Time joins game lap timers using completed-lap duration. If timing is not
  active (such as an untimed playground), advancing live packets can use a
  Stopwatch capture clock, explicitly flagged TimeIsCaptureClock. Circuit
  timing comparisons must reject that fallback. Paused/replay/AI frames are
  excluded before timing. A capture clock is not a simulated physics clock.

Setup: choose AC or ACC in the coach, run only that game, enter a driving
session, and use windowed/borderless mode for the desktop overlay. No app
must be enabled inside AC, no plugin copied, no UDP settings changed.

Validation status: synthetic byte and clock fixtures only. No running AC or
ACC driving session was used to certify this integration during development.
