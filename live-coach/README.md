# INTS Live Coach 0.1

Windows x64에서 실제 심레이싱 게임의 텔레메트리를 받아 작은 오버레이와 한국어 원리 코칭을 보여 주는 첫 연결 프로토타입입니다. `INTS-Live-Coach.exe`를 실행하면 됩니다. 별도 계정·서버·API 키·패키지 설치는 없습니다. Windows의 .NET Framework 4.x를 사용합니다.

이번 버전은 **합성 데이터 검사를 통과한 개발 빌드**입니다. 초기 LMU 대기 화면은 Windows에서 열어 확인했습니다. 게임 선택·원리 탭을 포함한 최종 통합 화면의 육안 확인은 사용자 Esc 입력으로 중단됐습니다. 각 게임을 실제로 주행하면서 연결·수치·코칭을 검증한 버전은 아닙니다.

## 시작하기

1. 실행 파일을 열고 상단에서 게임과 **레이싱 / 랠리 / 드리프트**를 선택합니다.
2. **원리 배우기** 탭에서 목표·원리·연습 순서·확인할 변화를 읽습니다. 게임 없이도 이용할 수 있습니다.
3. 아래 연결 설정을 적용한 뒤 게임에서 직접 차량을 운전합니다. 오버레이는 테두리 없는 창 또는 창 모드에서 사용합니다.
4. **오버레이 보기**를 누르고 원하는 위치로 드래그합니다. **마우스 통과**를 켜면 게임 조작을 가로채지 않습니다. `Ctrl+Alt+O`로 통과 상태를 전환합니다.
5. 입력 하나만 바꿔 연습합니다. 관측 근거가 쌓이고 조작이 안정되면 짧은 설명을 표시합니다. 설치된 한국어 음성이 있을 때 음성 코칭을 선택할 수 있습니다. 기본값은 꺼짐입니다.

레이싱 거리 비교는 처음 연결한 불완전한 랩을 버리고, 출발선을 통과한 뒤 다시 출발선까지 온전히 기록한 유효 랩을 기준으로 삼습니다. 다음 랩의 기준은 랩 도중 바뀌지 않습니다. 흰 페달 표시는 같은 위치의 내 기준 랩 입력입니다.

## 게임별 범위

| 게임 | 연결 | 이번 버전의 코칭 범위 |
|---|---|---|
| LMU | 내장 공유 메모리와 설치된 공식 SDK 형식 확인 | 입력·원리·유효한 이전 랩의 거리 비교 |
| AMS2 | Project CARS 2 공유 메모리 | 입력·원리·유효한 이전 랩의 거리 비교 |
| ACC | 내장 공유 메모리 | 입력·원리. 기본 공유 메모리에 유효한 코스 길이가 없어 거리별 이전 랩 비교는 비활성 |
| AC | 내장 공유 메모리 | 입력·슬라이드 크기 관찰·드리프트 원리. 권위 있는 현재 랩 유효성 신호가 없어 기준 랩 비교는 비활성 |
| EA WRC | localhost UDP 표준 `wrc/session_update` 패킷 | 랠리 입력·원리. 차량/스테이지 식별과 유효 랩 비교는 미지원 |

차량·게임의 타이어 물리를 복제하는 프로그램은 아닙니다. 실제 게임이 보고한 입력과 반응을 관찰합니다. 데이터가 없는 채널은 미측정으로 남기며 가상의 값으로 채우지 않습니다. 게임마다 조향 부호 규칙이 달라 오버레이는 좌우 화살표 대신 게임의 정규화된 입력 수치를 표시합니다.

### LMU

- `Gameplay → Enable Plugins`를 켜고 게임을 재시작합니다. 추가 플러그인 DLL은 필요하지 않습니다.
- Steam 설치 경로에서 `Support/SharedMemoryInterface`를 자동으로 찾습니다. 특수 설치 경로는 `LMU_SDK_DIR` 환경 변수로 이 폴더를 지정할 수 있습니다.
- 검토한 SDK와 헤더 해시가 다르면 연결을 중단합니다. 게임 업데이트 뒤에는 새 구조를 검토해야 할 수 있습니다. 게임 버전 문자열만 보고 메모리 형식을 추측하지 않습니다.

### ACC / AC

- 게임에서 차량에 탑승합니다. 추가 DLL이나 방송용 비밀번호는 필요하지 않습니다.
- 두 게임이 공유 메모리 이름을 재사용하므로 동시에 실행하지 않습니다. 게임 선택과 실제 실행 프로그램이 맞아야 합니다.
- AC의 일부 드리프트 맵은 랩 시계가 움직이지 않습니다. 이 경우 입력 관찰에 로컬 수집 시계를 사용하며, 이를 실제 랩타임으로 평가하지 않습니다.
- ACC의 거리 비교 확장은 공식 Broadcasting `TrackData`의 코스 길이를 연결할 수 있도록 별도 훅을 둡니다. 이번 실행 파일은 그 연결을 구현하지 않았습니다.

### AMS2

- `Options → System → Shared Memory`를 **Project CARS 2**로 설정합니다.
- 직접 운전하는 세션에서 사용합니다. 관전/AI 운전 여부를 모든 상황에서 판별할 수는 없습니다.
- 방향 부호가 검증되지 않은 차량 로컬 속도·가속도 채널은 사용하지 않습니다. 따라서 입력 변화에 대한 설명은 가능하지만 모든 슬라이드 원인을 판단하지는 않습니다.

### EA WRC

- 게임을 한 번 실행해 텔레메트리 설정 파일이 만들어진 상태여야 합니다.
- 사용자 문서의 `My Games/WRC/telemetry` 아래 `config.json`에서 **표준 `wrc` 구조, `session_update`, `127.0.0.1`, UDP 20777** 출력이 필요합니다. 정확한 항목 예시는 [WRC 연결 안내](WRC-SETUP.md)를 따릅니다.
- 앱은 설정 파일을 자동 수정하지 않으며 기존 SimHub 등의 출력을 덮어쓰지 않습니다.
- 기본 패킷은 보조 장치 적용 후의 입력을 보고합니다. 순수한 운전자 원입력으로 단정하지 않습니다. 리플레이/AI 제어를 확실히 구분할 신호도 없으므로 실제 직접 주행에서 사용합니다.
- 현재 WRC 어댑터는 차체 회전 속도를 제공하지 않아 펜듈럼 동작의 자동 인식은 보류합니다. 펜듈럼의 원리와 단계별 과제는 가이드에서 볼 수 있습니다.

## 원리를 배우는 코칭

설명은 세 단계를 구분합니다.

1. **관측:** 일정 시간 동안 어떤 입력과 반응이 나왔는지.
2. **가능한 원리:** 타이어가 감속·회전을 함께 감당하거나, 입력 변화가 차체 회전과 맞물릴 수 있다는 설명. 실제 실패 원인의 확정은 아닙니다.
3. **다음 연습:** 진입 속도·브레이크 해제·조향 속도·가속량 중 한 가지만 바꿔 볼 과제.

레이싱은 제동과 회전의 접지 공유, 브레이크 해제, 입력 속도를 배웁니다. 랠리는 느슨한 노면의 접지, 하중 이동과 펜듈럼 준비, 핸드브레이크와 클러치의 역할을 배웁니다. 드리프트는 원돌이 → 8자 전환 → 게임 속 짧은 토우게 순서로 가속·카운터 조향·각도 유지의 관계를 배웁니다.

원돌이에 실패했다는 사실만으로 클러치 킥을 처방하지 않습니다. 슬립·회전 측정이 없으면 그 원인은 판단 보류하고 기본 과제를 안내합니다. 차량별 적정 속도, 전문가 최속 라인, 정답 브레이킹 지점을 생성하지 않습니다.

## 기록과 제한

- 비교 대상은 **내 이전 유효 랩**입니다. 더 빠른 운전의 정답이 아닙니다.
- 위치 데이터와 페달 데이터의 갱신 주기가 다를 수 있습니다. 거리 차이는 근사로 표시하고, 추정 오차보다 작은 차이로 교정을 지시하지 않습니다. 오차 추정도 보장된 계측 오차 한계는 아닙니다.
- 피트·무효 랩·연결 중단·랩 이동은 신호가 제공되는 범위에서 비교에서 제외합니다. 연료·타이어·노면·트래픽·셋업 차이까지 통제한 인과 분석은 아닙니다.
- 코너 감지는 제동과 가속 패턴을 사용합니다. 모든 코너의 공식 이름이나 연결 코너를 정확히 분리하지는 않습니다.
- 원리 가이드는 먼저 읽고 주행합니다. 긴 설명은 메인 창에서 확인하고, 오버레이는 짧은 관측과 다음 행동에 집중합니다.
- 기록은 메모리에 제한된 수량으로 보관합니다. **이번 주행 내보내기**를 눌러야 선택한 경로에 JSON을 저장하며 서버로 전송하지 않습니다. 전체 세션 영상이나 무제한 텔레메트리 기록기는 아닙니다.
- 실제 게임의 차량을 되감거나 조작하지 않습니다. 이 실행 파일에는 게임 영상 슬로모션이나 코너 직전으로 자동 복귀하는 기능이 없습니다.

## 소스에서 빌드

Windows PowerShell에서:

```powershell
.\live-coach\build.ps1 -Test
```

출력은 `build/live-coach/INTS-Live-Coach.exe`, 합성 데이터 검사기는 `INTS-Coach-Checks.exe`입니다. SDK·NuGet 설치가 필요하지 않습니다. `INTS-Coach-Checks.exe --probe`는 LMU에서 실제 프레임이 수신되는지만 확인하며 게임을 실행하거나 설정을 바꾸지 않습니다.

SDK 구조·출처·라이선스·패킷 버전은 함께 제공한 `*NOTICES.txt`를 참고하세요. 게임의 독점 헤더·DLL·자산은 배포하지 않습니다.
