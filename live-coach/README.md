# INTS Live Coach 0.3.0

Windows x64에서 실제 심레이싱 게임의 텔레메트리를 받아 작은 오버레이와 한국어 원리 코칭을 보여 주는 첫 연결 프로토타입입니다. `INTS-Live-Coach.exe`를 실행하면 됩니다. 별도 계정·서버·API 키·패키지 설치는 없습니다. Windows의 .NET Framework 4.x를 사용합니다.

이번 버전은 **합성 데이터 검사를 통과한 개발 빌드**입니다. 초기 LMU 대기 화면은 Windows에서 열어 확인했습니다. 게임 선택·원리 탭을 포함한 최종 통합 화면의 육안 확인은 사용자 Esc 입력으로 중단됐습니다. 각 게임을 실제로 주행하면서 연결·수치·코칭을 검증한 버전은 아닙니다.

0.3.0에서는 **불러온 기준으로 코너 탈출 후 오버레이 코칭**을 제공합니다. 손실 구간 → 관측된 입력 차이 → 다음 랩에서 바꿀 한 가지 → 관련 원리를 짧게 표시합니다. 기준 파일 라이브러리에서 다른 서킷도 선택할 수 있습니다. 완주 후 상세 그래프와 100 m 구간 손실 비교도 유지하며 화면을 강제로 전환하지 않습니다.

## 코너 뒤 오버레이 사용

1. **핫랩과 비교** 탭의 목록에서 현재 게임·차량·서킷에 맞는 기준을 선택합니다. 개인용 묶음에는 아래 실제 기록들이 들어 있습니다.
2. **기준 주행으로 코너 뒤 코칭**을 켭니다. LMU에 탑승한 뒤 SDK의 팀/리버리 이름이 다르면 **차량·코스 이름 연결**에서 같은 모델·세대·레이아웃임을 확인합니다. 완주 전에도 연결할 수 있습니다.
3. LMU MoTeC 기준에는 **MoTeC ↔ 실시간 탐색 정렬**이 필요합니다. 이는 실시간 채널 매핑 미검증을 인정하는 탐색 옵션입니다. 파일을 바꾸면 이름 연결·정렬·버전 옵션을 다시 확인합니다.
4. **실전 코치 → 오버레이 보기**를 누릅니다. 청록 페달 표시는 불러온 기준의 같은 위치 입력입니다. 기준 코칭을 끄면 기존 내 이전 랩/원리 코칭으로 돌아갑니다. 다른 게임의 기준은 적용하지 않습니다.
5. 구간 전체를 관측하고 조작이 0.6초 이상 안정되면 최대 8초간 코칭합니다. 다음 코너, 무효 랩, 피트, 리플레이, 데이터 중단에서는 이전 알림을 지웁니다. 한국어 음성이 있으면 다음 과제 한 문장만 읽으며 바빠지면 중단합니다. 원리는 화면에 남깁니다.

기준의 지속적인 제동 또는 감속을 동반한 조향에서 구간을 추출하고 가까운 복합 코너를 묶습니다. 공식 코너 이름·에이펙스·모든 전개 가속 코너를 인식하는 기능은 아닙니다. 시간 차이의 전반/중반/후반은 **고정된 거리 구간의 3등분**입니다. 늦은 조향 해제를 관찰하느라 더 기다려도 시간 측정의 종료 위치를 바꾸지 않습니다.

진입 속도가 다르면 먼저 속도를 맞추고, 제동 해제가 늦으며 탈출 속도도 낮은 등 근거가 있을 때만 해제 시점 하나를 부드럽게 바꾸는 연습을 제안합니다. 조향은 각 랩 자체 최대 입력 대비 풀리는 시점만 비교합니다. 휠 각도·좌우 방향을 복사시키거나 언더스티어 원인을 확정하지 않습니다. 표본 오차보다 작은 차이에 정확한 미터 단위 교정을 지시하지 않습니다.

## 포르쉐 992 · 몬자 기준 주행

첫 소스는 [PS_Racing의 LMU Porsche 992 Monza 1:49.069 핫랩](https://www.youtube.com/watch?v=jtPPwxAlu0c)과 제작자가 설명에 제공한 [무료 MoTeC 원본](https://drive.google.com/drive/folders/1GACcrJyLckzcjllVK45ROfGzPZMp3Sak)입니다. 실제 파일을 내려받아 검사했으며, 랩 시계와 Last/Best Laptime의 **109.06884초**가 일치합니다. 게임 버전·BoP·랩 유효 플래그는 확인하지 못했습니다. 현재 버전의 목표 기록이나 세계 최속 기록으로 인증한 것은 아닙니다.

- 원본 속도·브레이크·가속·조향은 10 Hz, 코스 거리·횡위치는 5 Hz입니다. 변환 파일은 거리 시각에 맞춘 **545개 표본**입니다.
- 실측 대기 온도 21°C, 노면 28.310–28.428°C, 연료 약 7.60→4.29 L입니다. 제작자 설명의 노면 30°C와 구분해 보존합니다.
- 정확한 출발/종료 경계 표본은 없습니다. 9.40125–5772.7755 m 구간만 사용하며, 이 파일과의 **전체 랩 델타는 표시하지 않습니다**. 공통 시작점 이후 누적 차이와 구간별 차이는 비교합니다.
- GPS의 게임 월드 좌표 변환이 미확인이라 지도 위 레이싱 라인을 만들어 넣지 않았습니다. 대신 원본 `Path Lateral`의 **근사 코스 중심 경로 기준 횡위치**를 별도 그래프로 표시합니다. 부호를 물리적 좌/우로 단정하지 않습니다.
- MoTeC의 거리·횡위치와 실시간 공유 메모리 채널 대응은 실제 주행 대조 전입니다. **탐색 정렬**을 직접 선택한 경우에만 교차 비교합니다. 이 결과는 검증된 미터 단위 운전 지시가 아닙니다.

사용 순서:

1. 개인용 실행 폴더에는 `references/lmu-porsche992-monza-psracing.json`을 함께 두었습니다. **핫랩과 비교** 탭에서 자동으로 열립니다. 공개 소스/공개 배포에는 원본과 변환 주행 데이터가 없습니다.
2. LMU에서 포르쉐 992·몬자로 출발선을 통과한 뒤 완전한 유효 랩을 마칩니다. 내 최근 완주 랩이 자동으로 추가됩니다. **내 완주 랩 저장**으로 보관하고 나중에 다시 열 수 있습니다.
3. SDK의 팀/리버리 이름과 기준 파일의 모델명이 다르면 **차량·코스 이름 연결**에서 실제 같은 차량·세대·레이아웃임을 확인합니다. 다른 게임, 거리 기준, 트랙 길이 검사는 계속 적용됩니다. 동일 세션의 다음 랩에는 확인한 이름 연결을 재사용합니다.
4. **MoTeC ↔ 실시간 거리·횡위치 탐색 정렬**을 선택합니다. 알려진 버전이 다를 때만 별도 버전 비교 옵션이 필요합니다. 미확인 조건은 **출처 · 조건 · 읽는 법**에서 확인합니다.
5. **어디서 잃었나**에서 구간을 누르고 **±200 m 확대**를 켭니다. 진입 속도 → 제동 해제 → 최저 속도 → 탈출 가속을 함께 비교합니다. 제동 표의 ‘더 뒤에서’는 코스 진행 방향상 늦은 위치이며, 단독으로 잘못이라고 판정하지 않습니다.

원본 자료는 개인 다운로드 용도로 공개됐으나 재배포 허가는 확인되지 않았습니다. 개인용 기준 파일을 공개 저장소에 추가하지 마세요. 공개 저장소에는 독립 변환기와 출처·설정 예시만 있습니다. 아래 변환기는 Node.js 18 이상이 필요하며, 완성된 앱/JSON을 사용하는 데 Node.js는 필요하지 않습니다.

```powershell
node live-coach/import-motec.mjs '다운로드한 원본.ld' live-coach/reference-import.example.json '새 기준 파일.json'
node --test live-coach/import-motec.test.mjs
```

예시는 이 특정 기록의 실제 채널상 랩 번호 11에 맞춰져 있습니다. 다른 기록은 차량·코스·단위·랩 번호와 시계를 확인한 뒤 설정을 바꿔야 합니다. `.ldx`의 화면 표시 랩 번호와 채널의 랩 번호는 같다고 가정하지 않습니다. 다른 게임용 `.ld`를 LMU로 바꿔 표기해 가져오는 용도가 아닙니다. 상세 출처와 해석은 `REFERENCE-NOTICES.txt`를 참고하세요.

## 시작하기

1. 실행 파일을 열고 상단에서 게임과 **레이싱 / 랠리 / 드리프트**를 선택합니다.
2. **원리 배우기** 탭에서 목표·원리·연습 순서·확인할 변화를 읽습니다. 게임 없이도 이용할 수 있습니다.
3. 아래 연결 설정을 적용한 뒤 게임에서 직접 차량을 운전합니다. 오버레이는 테두리 없는 창 또는 창 모드에서 사용합니다.
4. **오버레이 보기**를 누르고 원하는 위치로 드래그합니다. **마우스 통과**를 켜면 게임 조작을 가로채지 않습니다. `Ctrl+Alt+O`로 통과 상태를 전환합니다.
5. 입력 하나만 바꿔 연습합니다. 관측 근거가 쌓이고 조작이 안정되면 짧은 설명을 표시합니다. 설치된 한국어 음성이 있을 때 음성 코칭을 선택할 수 있습니다. 기본값은 꺼짐입니다.

레이싱 거리 비교는 처음 연결한 불완전한 랩을 버리고, 출발선을 통과한 뒤 다시 출발선까지 온전히 기록한 유효 랩을 기준으로 삼습니다. 다음 랩의 기준은 랩 도중 바뀌지 않습니다. 흰 페달 표시는 같은 위치의 내 기준 랩 입력입니다.

| 게임 | 연결 | 이번 버전의 코칭 범위 |
|---|---|---|
| LMU | 내장 공유 메모리와 설치된 공식 SDK 형식 확인 | 입력·원리·유효한 이전 랩의 거리 비교 |
| AMS2 | Project CARS 2 공유 메모리 | 입력·원리·유효한 이전 랩의 거리 비교 |
| ACC | 내장 공유 메모리 | 입력·원리. 기본 공유 메모리에 유효한 코스 길이가 없어 거리별 이전 랩 비교는 비활성 |
| AC | 내장 공유 메모리 | 입력·슬라이드 크기 관찰·드리프트 원리. 권위 있는 현재 랩 유효성 신호가 없어 기준 랩 비교는 비활성 |
| EA WRC | localhost UDP 표준 `wrc/session_update` 패킷 | 랠리 입력·원리. 차량/스테이지 식별과 유효 랩 비교는 미지원 |
| Assetto Corsa Rally (ACR) | 별도 ACR 프로세스 확인 + 공통 공유 메모리 앞부분 | 랠리 입력·원리 시험 연결. 완주 유효성·이전 스테이지 비교는 미지원 |

차량·게임의 타이어 물리를 복제하는 프로그램은 아닙니다. 실제 게임이 보고한 입력과 반응을 관찰합니다. 데이터가 없는 채널은 미측정으로 남기며 가상의 값으로 채우지 않습니다. 게임마다 조향 부호 규칙이 달라 오버레이는 좌우 화살표 대신 게임의 정규화된 입력 수치를 표시합니다.

### LMU

- `Gameplay → Enable Plugins`를 켜고 게임을 재시작합니다. 추가 플러그인 DLL은 필요하지 않습니다.
- Steam 설치 경로에서 `Support/SharedMemoryInterface`를 자동으로 찾습니다. 특수 설치 경로는 `LMU_SDK_DIR` 환경 변수로 이 폴더를 지정할 수 있습니다.
- 검토한 SDK와 헤더 해시가 다르면 연결을 중단합니다. 게임 업데이트 뒤에는 새 구조를 검토해야 할 수 있습니다. 게임 버전 문자열만 보고 메모리 형식을 추측하지 않습니다.

### ACC / AC

- 게임에서 차량에 탑승합니다. 추가 DLL이나 방송용 비밀번호는 필요하지 않습니다.
- 두 게임이 공유 메모리 이름을 재사용하므로 동시에 실행하지 않습니다. 게임 선택과 실제 실행 프로그램이 맞아야 합니다.
- AC의 일부 드리프트 맵은 랩 시계가 움직이지 않습니다. 이 경우 입력 관찰에 로컬 수집 시계를 사용하며, 이를 실제 랩타임으로 평가하지 않습니다.
- ACC의 거리 비교 확장은 공식 Broadcasting `TrackData`의 코스 길이를 연결할 수 있도록 별도 훅을 둡니다. 이번 실행 파일은 그 연결을 구현하지 않았습니다.

### AMS2

- `Options → System → Shared Memory`를 **Project CARS 2**로 설정합니다.
- 직접 운전하는 세션에서 사용합니다. 관전/AI 운전 여부를 모든 상황에서 판별할 수는 없습니다.
- 방향 부호가 검증되지 않은 차량 로컬 속도·가속도 채널은 사용하지 않습니다. 따라서 입력 변화에 대한 설명은 가능하지만 모든 슬라이드 원인을 판단하지는 않습니다.

### Assetto Corsa Rally / AC Rally / ACR

- 게임 선택에서 **AC Rally**를 고르면 랠리 모드로 전환됩니다. 기존 **AC** 항목은 원래 Assetto Corsa의 드리프트·토우게용 연결입니다.
- ACR에서 스테이지에 진입해 직접 운전합니다. 다른 AC·ACC·EVO는 종료해야 공유 메모리 충돌을 피할 수 있습니다. 추가 DLL이나 UDP 설정은 사용하지 않습니다.
- 속도·가속·제동·조향을 관찰하고, **원리 배우기 → 랠리**의 그래벌·하중 이동·펜듈럼·핸드브레이크·클러치 과제로 연결합니다.
- 설치된 게임에 공개 SDK가 없어 [ACR 텔레메트리 제작자의 구현](https://github.com/Zillionnn/AC_Rally_Telemery)과 [다른 실제 ACR 기록 도구](https://github.com/decnet100/acr_telemetry)의 공통 형식만 참고한 시험 연결입니다. 공식 SDK 호환성이나 현재 설치 빌드의 실제 주행 검증을 완료한 것은 아닙니다.
- 해석이 확인되지 않은 차체 회전축·클러치·핸드브레이크 값은 미측정으로 둡니다. 펜듈럼이나 핸드브레이크 사용의 성공·실패를 자동 판정하지 않습니다. 원리 가이드는 이용할 수 있습니다.
- 서킷 랩 유효성이나 이전 스테이지 대비 시간차를 만들지 않습니다. 기록에 표시된 시계 종류와 확인 범위는 JSON 내보내기에도 포함됩니다. 연결 세부 근거는 `ACR-NOTICES.txt`를 참고하세요.

### EA WRC

- 게임을 한 번 실행해 텔레메트리 설정 파일이 만들어진 상태여야 합니다.
- 사용자 문서의 `My Games/WRC/telemetry` 아래 `config.json`에서 **표준 `wrc` 구조, `session_update`, `127.0.0.1`, UDP 20777** 출력이 필요합니다. 정확한 항목 예시는 [WRC 연결 안내](WRC-SETUP.md)를 따릅니다.
- 앱은 설정 파일을 자동 수정하지 않으며 기존 SimHub 등의 출력을 덮어쓰지 않습니다.
- 기본 패킷은 보조 장치 적용 후의 입력을 보고합니다. 순수한 운전자 원입력으로 단정하지 않습니다. 리플레이/AI 제어를 확실히 구분할 신호도 없으므로 실제 직접 주행에서 사용합니다.
- 현재 WRC 어댑터는 차체 회전 속도를 제공하지 않아 펜듈럼 동작의 자동 인식은 보류합니다. 펜듈럼의 원리와 단계별 과제는 가이드에서 볼 수 있습니다.

## 원리를 배우는 코칭

설명은 세 단계를 구분합니다.

1. **관측:** 일정 시간 동안 어떤 입력과 반응이 나왔는지.
2. **가능한 원리:** 타이어가 감속·회전을 함께 감당하거나, 입력 변화가 차체 회전과 맞물릴 수 있다는 설명. 실제 실패 원인의 확정은 아닙니다.
3. **다음 연습:** 진입 속도·브레이크 해제·조향 속도·가속량 중 한 가지만 바꿔 볼 과제.

레이싱은 제동과 회전의 접지 공유, 브레이크 해제, 입력 속도를 배웁니다. 랠리는 느슨한 노면의 접지, 하중 이동과 펜듈럼 준비, 핸드브레이크와 클러치의 역할을 배웁니다. 드리프트는 원돌이 → 8자 전환 → 게임 속 짧은 토우게 순서로 가속·카운터 조향·각도 유지의 관계를 배웁니다.

원돌이에 실패했다는 사실만으로 클러치 킥을 처방하지 않습니다. 슬립·회전 측정이 없으면 그 원인은 판단 보류하고 기본 과제를 안내합니다. 차량별 적정 속도, 전문가 최속 라인, 정답 브레이킹 지점을 생성하지 않습니다.

## 기록과 제한

- 기준 코칭 사용 시 오버레이는 **불러온 실제 기록**과 비교합니다. 끄면 기존 **내 이전 유효 랩/원리 코칭**을 사용합니다. 둘 다 모든 조건에서의 보편적인 정답은 아닙니다.
- 위치 데이터와 페달 데이터의 갱신 주기가 다를 수 있습니다. 거리 차이는 근사로 표시하고, 추정 오차보다 작은 차이로 교정을 지시하지 않습니다. 오차 추정도 보장된 계측 오차 한계는 아닙니다.
- 피트·무효 랩·연결 중단·랩 이동은 신호가 제공되는 범위에서 비교에서 제외합니다. 연료·타이어·노면·트래픽·셋업 차이까지 통제한 인과 분석은 아닙니다.
- 코너 감지는 제동과 가속 패턴을 사용합니다. 모든 코너의 공식 이름이나 연결 코너를 정확히 분리하지는 않습니다.
- 원리 가이드는 먼저 읽고 주행합니다. 긴 설명은 메인 창에서 확인하고, 오버레이는 짧은 관측과 다음 행동에 집중합니다.
- 기록은 메모리에 제한된 수량으로 보관합니다. **이번 주행 내보내기**를 눌러야 선택한 경로에 JSON을 저장하며 서버로 전송하지 않습니다. 전체 세션 영상이나 무제한 텔레메트리 기록기는 아닙니다.
- 실제 게임의 차량을 되감거나 조작하지 않습니다. 이 실행 파일에는 게임 영상 슬로모션이나 코너 직전으로 자동 복귀하는 기능이 없습니다.
- 오버레이에서 전달한 최대 100개 기준 코칭 이벤트는 **이번 주행 내보내기**의 `referenceCoaching`에 출처·구간 차이·원리·과제·한계와 함께 저장됩니다. 기준 파일을 바꾸면 이전 기준의 이벤트는 초기화됩니다.

## 소스에서 빌드

Windows PowerShell에서:

```powershell
.\live-coach\build.ps1 -Test
node --test live-coach/import-motec.test.mjs live-coach/import-acc-motec.test.mjs
```

출력은 `build/live-coach/INTS-Live-Coach.exe`, 합성 데이터 검사기는 `INTS-Coach-Checks.exe`입니다. SDK·NuGet 설치가 필요하지 않습니다. `INTS-Coach-Checks.exe --probe`는 LMU에서 실제 프레임이 수신되는지만 확인하며 게임을 실행하거나 설정을 바꾸지 않습니다. ACR 연결만 확인하려면 `INTS-Coach-Checks.exe --probe acr`을 실행합니다.

SDK 구조·출처·라이선스·패킷 버전은 함께 제공한 `*NOTICES.txt`를 참고하세요. 게임의 독점 헤더·DLL·자산은 배포하지 않습니다.
