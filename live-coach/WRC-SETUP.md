# EA SPORTS WRC 연결

현재 어댑터는 EA WRC가 생성한 표준 `wrc` / `session_update` UDP 형식을 **127.0.0.1:20777**에서 받습니다. 게임 설정 파일을 자동 변경하지 않습니다.

1. 게임을 한 번 실행한 뒤 종료합니다.
2. 문서 폴더의 `My Games/WRC/telemetry/config.json`을 백업합니다. OneDrive로 문서 폴더를 옮겼다면 그 문서 폴더를 사용합니다.
3. `udp` → `packets` 배열에서 `structure: "wrc"`, `packet: "session_update"` 항목을 찾아 아래처럼 수정합니다. 기존 SimHub의 `wrc_simhub` 항목과 29888/29889 포트 설정 등은 그대로 둡니다. 전체 파일을 아래 조각으로 덮어쓰지 마세요.

```json
{
  "structure": "wrc",
  "packet": "session_update",
  "ip": "127.0.0.1",
  "port": 20777,
  "frequencyHz": 60,
  "bEnabled": true
}
```

4. 위 항목이 없다면 기존 `packets` 배열에 항목 하나로 추가합니다. JSON의 항목 사이 쉼표에 유의하세요. 최상위 `schema: 2`와 다른 설정은 유지합니다.
5. 게임을 다시 실행하고 코치에서 EA WRC를 선택합니다. 코치는 연결 대기 중 설정을 다시 확인합니다. 연결 중 포트나 형식을 변경했다면 코치도 재시작합니다.
6. 스테이지 출발 후 데이터가 들어오는지 확인합니다. 수신되지 않으면 `telemetry/log.txt`의 게임 설정 오류와 20777 포트를 사용하는 다른 앱을 확인합니다. 코치는 포트를 독점 수신하므로 다른 앱이 먼저 사용 중이면 연결하지 않습니다.

게임의 `telemetry/readme` 파일들은 시작할 때 다시 생성되는 문서입니다. 편집 대상이 아닙니다. `WRC_TELEMETRY_DIR` 환경변수로 다른 telemetry 폴더를 명시할 수 있습니다.

## 현재 읽는 값과 한계

- 속도, 기어, 가속·제동·클러치·조향·핸드브레이크, 스테이지 거리와 길이, 차량 운동을 읽습니다.
- WRC의 조작 값은 **보조장치와 게임의 개입이 적용된 뒤**의 값입니다. 실제 페달 원신호와 같다고 가정하지 않습니다.
- 위치·속도·가속도는 게임이 제공한 차량 방향 벡터로 투영합니다. 월드 좌표를 그대로 차량의 옆 방향으로 취급하지 않습니다.
- 표준 패킷에는 차량/노선 ID, 인간 직접 운전 여부, 리플레이 여부, 유효 완주 판정이 없습니다. 이 연결로 유효 랩 기준, 같은 차량/같은 스테이지의 이전 기록 비교, 리플레이 자동 판별을 주장하지 않습니다. 직접 주행 중에 사용하세요.
- 재생성된 공식 스키마가 확인된 버전과 다르면 코칭을 중지합니다. 패킷 길이가 같다는 이유만으로 새 형식을 추정하지 않습니다.
- 합성 데이터 테스트는 통과했지만 실제 게임에서의 수신·주행 전체 검증은 별도입니다.

공식 설정 절차: [EA WRC UDP 가이드](https://forums.ea.com/t5/s/tghpe58374/attachments/tghpe58374/wrc-general-discussion-en/2667/1/EA%20SPORTS%20WRC%20-%20UDP%20Telemetry%20Guide%20%28v1.3%29.pdf). 최신 필드 형식은 설치된 게임이 생성한 `readme/channels.json`과 `readme/udp/wrc.json`을 우선합니다. 확인된 해시와 포맷은 `ADAPTER-NOTICES.txt`에 기록했습니다.
