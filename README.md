# INTS'Drive_to_Survive

레이싱 → 랠리 → 드리프트 → 포뮬러를 연결하는 한국어 **차량 거동 실험실·훈련 가이드**입니다. 휠 없이 개념을 익히고 실제 심에서 확인할 질문과 기록을 남깁니다.

**0.4 학습 프로토타입**입니다. LMU·ACC·iRacing 등의 물리를 복제하거나 특정 레이팅 달성을 보장하지 않습니다. 모델 수치와 서킷 지오메트리는 교육용 근사입니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 Node.js 18 이상에서 `npm start`를 실행한 뒤 `http://127.0.0.1:8765`를 엽니다. 패키지 설치는 필요하지 않습니다. 패드 인식과 저장은 브라우저에 따라 다르므로 로컬 서버 또는 HTTPS를 권장합니다.

- `npm test`: 모든 모델·기하·입력·기록·학습 로직 검사
- `npm run build:offline`: `build/INTS-Drive_to_Survive.html` 단일 파일 생성

앱은 외부 폰트·이미지·패키지·API를 로드하지 않습니다. 참고 자료는 사용자가 링크를 열 때만 이동합니다.

## 학습 흐름

1. **연습 시작**: 차량·코스가 준비된 8개 과제에서 목표 하나와 조작 순서부터 확인합니다. 첫 경험은 직선 제동입니다.
2. **서킷 훈련**: 몬자 T1·레스모 1, 뉘르 GP T1을 짧게 반복한 뒤 몬자 한 바퀴로 연결합니다. 랠리 저속 헤어핀·드리프트 준비 원 선회도 제공합니다.
3. **결과와 이유**: 실패 전후를 0.25×·0.5×·1×로 재생하고 같은 코스 위치의 내 입력과 시범을 비교합니다. 제동 해제·조향 변화 버튼으로 해당 위치를 찾고 다음 시도에서 바꿀 한 가지를 정합니다.
4. **자유 실험 / 5회 반복**: 조건을 직접 바꾸거나 같은 90° 코너 5회의 구간 시간·유효율·편차를 비교합니다.
5. **원리 & 판단 / 종합 가이드**: 6개 기초 강의·8개 상황 문제·24개 주제에서 개념과 실제 심 과제를 확인합니다.
6. **실전 연계**: 실제 게임의 랩타임·조건을 직접 기록하고 차량별 코너 기준점을 저장합니다.

자동 시범은 같은 물리 모델을 조작하는 경로 추종 예시입니다. 최적 레이싱 라인·핫랩이 아니며 내 기록이나 목표 달성으로 저장하지 않습니다. 안내 연습은 도로 밖 누적 시간이 2초를 넘으면 결과를 표시합니다. ‘현재 시도 분석’으로 도중에 끝낼 수도 있습니다.

실패 분석은 **관측된 사실 / 가능성 있는 원인 / 판단할 기록 부족**을 구분합니다. 첫 문제 이전 2초의 지속적인 제동·조향·가속·타이어 요구·슬립을 연결하며, 문제 뒤의 수치를 앞선 실패 원인으로 쓰지 않습니다. 단순 규칙 기반 교육용 진단이며 실제 게임 텔레메트리 분석이나 인과관계 확정은 아닙니다.

목표 달성 여부는 `intsTrainingProgressV1`에 최근 직접 주행 결과만 저장합니다. 자세한 시계열은 현재 탭의 마지막 시도에서만 보며 재시작/새로고침 때 지워집니다. 이전 기록은 요약으로 남습니다.

## 슬로모션과 시범 비교

첫 이탈·큰 슬립 전 4초와 후 2초를 기본 구간으로 표시합니다. 완주했더라도 진입 속도·브레이크 해제 등 과제 조건을 놓치면 해당 측정 지점으로 이동합니다. 전체 주행, 반복, 일시정지, 0.1초 이동, 슬라이더 이동을 지원하며 탭 전환·포커스 이탈 시 재생을 멈춥니다. 재생은 점수·주행 기록·실제 차량 상태를 바꾸지 않습니다.

안내 연습의 시범은 **같은 차량·노면·구동·보조장치·시작 속도**로 생성합니다. 두 화면은 공통 카메라를 사용하고 내 기록의 시간에 맞춰 재생하되, 시범은 **같은 경로 진행 거리**로 정렬합니다. 시범 자체 시간은 별도로 표시합니다. 속도가 다르면 동일한 조작량이 동일한 결과를 뜻하지 않습니다. 이탈 중 진행 거리는 실제 이동 거리와 달라질 수 있습니다.

브레이크·가속 막대, 방향이 있는 조향 표시, 거리 기준 제동/조향 그래프로 차이를 확인합니다. 제동 시작은 18% 이상, 해제 표시는 8% 이하가 0.15초 유지된 위치이며 순간적인 노이즈는 제외합니다. 시범이 도달하지 않은 위치에는 비교 수치를 만들지 않습니다. 경로 추종 시범은 최적 핫랩·실차 정답이 아닙니다.

최고 기록 하나보다 반복 가능한 페이스를 확인하세요. iRating 2k~3k를 목표로 삼을 수는 있지만 앱이 그 수준을 판정하거나 도달을 보장하지 않습니다.

## 차량 모델

| 계열 | 학습할 차이 | 수치의 성격 |
|---|---|---|
| GT3 | 프런트엔진 RWD, 공력, 접지 예산 기반 토크 보조 | M4 GT3 EVO 공개 제원 일부 참고 + 교육용 가정 |
| Rally1 | AWD, 낮은 노면 접지, 방향 전환 | Hyundai 2025 비하이브리드 공개 제원 일부 참고 + 가정 |
| AE86 | 경량 FR, 순정급 출력, 운전자 입력 | 1983 Levin 3도어 GTV 참고 + 운전자·전달출력 가정 |
| 하이퍼카 | MR, 높은 출력과 공력 | 가상 RWD 학습형; 하이브리드 없음 |
| 포뮬러 | 속도에 따른 큰 공력 차이 | 가상 고다운포스 RWD; 특정 F1 시즌 재현 없음 |
| FF / MR / RR | 구동·엔진 배치·무게배분·관성 | 비교를 위한 가상 모델 |

전륜·후륜·사륜은 **구동 방식**, 프런트엔진·미드십·리어엔진은 **엔진 배치**입니다. 차량 정보에서 공개 자료의 사실(`sourceFacts`)과 모델 가정(`assumptions`)을 구분합니다. 구동·보조를 바꾸면 비교 실험이 됩니다.

2025 Rally1은 EA WRC의 이전 하이브리드 연식과 다릅니다. AE86은 튜닝 드리프트 차가 아닙니다. GT3 질량·출력은 실제 게임의 BoP·패치별로 달라지므로 모델값을 실제 셋업 수치로 사용하지 마세요.

## 연습 코스

- 기초: 90° 코너, 500 m 직선 제동, 슬라럼, 헤어핀, 원돌이, 8자 경로.
- 종합: Monza GP 5,793 m / Nürburgring GP 5,148 m의 **공식 코너 순서·길이를 참고한 독자적 평면 도식**.
- 가상 코스: 680 m 랠리, 넓은 드리프트 패드, 780 m 연결 코너 토우게.

실제 서킷은 전체 길이만 공식 길이에 맞췄습니다. 코너 좌표·반경·폭은 측량 자료가 아니며 고저차·캠버·뱅킹·연석은 없습니다. 레이싱 라인·기어·브레이크 포인트 정답을 알려주는 지도가 아닙니다. 원돌이·8자·플레이그라운드는 자유 관찰 세션입니다.

화면은 출발 방향을 아래→위로 맞추며 물리 좌표는 그대로입니다. 안내 서킷은 추적 카메라로 시작하고 ⌖로 전체 도식과 전환합니다. 200·150·100·50 거리판은 **코스 중심선을 따라 회전 기준선까지 남은 모델 거리(m)**입니다. 실제 서킷 표지 위치나 권장 제동 지점을 재현한 것이 아닙니다. 레스모 접근 구간에는 앞선 로지아 구간이 일부 포함됩니다.

## 조작

| 입력 | 조작 |
|---|---|
| 키보드 | W/S 가속·제동, A/D 조향, E 핸드브레이크, Q 클러치 분리 |
| 공통 | Space 일시정지, R 재시작, ⌖ 전체/추적 카메라 |
| 마우스 | 누른 채 좌우 조향·상하 가속/제동 또는 유지형 슬라이더 |
| 표준 패드 | 왼쪽 스틱, RT 가속, LT 제동, B 핸드브레이크, LB 클러치 |

키보드는 속도에 따라 최대 조향을 줄입니다. 조향 표시는 앞바퀴 각도입니다. 0.5×는 관찰용이며 기록은 시뮬레이션 시간입니다. 포커스 이탈·탭 이동·설명 열기 시 일시정지합니다. 실제 패드 하드웨어 검증은 아직 없습니다.

## 물리와 한계

평면 비선형 bicycle model입니다. 슬립각 기반 횡력, 종횡력 결합, 네 바퀴 수직하중의 부하 민감도 합산, 질량·관성·출력·구동, 속도² 공력, 근사 엔진브레이크를 계산합니다. 내부 적분 간격은 최대 1/240초입니다.

`utilF/R`은 **요구량/한계**라 100%를 넘을 수 있습니다. 접지원의 점은 실제 힘입니다. 네 바퀴 하중은 독립 4륜 서스펜션 해석 결과가 아닙니다. TC 표시는 접지 예산에 따라 토크를 줄이는 교육용 제어이며 실제 TC 로직이 아닙니다.

핸드브레이크는 뒤축 추가 제동과 횡력 여유 감소만 근사합니다. 바퀴 잠김·재접지·센터 디퍼렌셜은 계산하지 않습니다. 클러치는 구동·근사 엔진브레이크 분리만 계산하며 **클러치 킥의 RPM·플라이휠 저장 에너지는 재현하지 않습니다.** 해당 가이드는 실제 심에서 수행할 별도 훈련입니다.

구현 범위 밖: 바퀴 회전·슬립률·실제 ABS, 기어·RPM, 완전 스핀·후진·90° 초과 슬립, 점프·서스펜션 스트로크, 타이어 열·압력·마모, 연료 변화, 하이브리드·회생제동, FFB, 게임별 보정. 상세 범위는 `GripPhysics.capabilities`와 `limitations`에 있습니다.

## 실전 기록과 서킷 가이드 확장

게임·실제 차량·트랙·연료/타이어/노면/셋업·질문·랩타임·다음 실험을 기록합니다. 랩은 `1:49.321` 또는 `109.321`, 무효 랩은 `!1:52.100`입니다. 중앙값·편차·범위·유효율·후반/전반 차이는 직접 입력값으로 계산하며 원인을 확정하지 않습니다. 게임 자동 연결은 없습니다.

코너 노트의 `trackId`, `vehicle`, `game`, `car`, `corner`, `reference`, `gear`, `conditions`, `status`, `warning`은 트랙 지오메트리와 분리되어 있습니다. `status`는 가설 또는 실제 심에서 확인한 자기기록입니다. 추후 거리 기반 텔레메트리·패치별 기준 주행·차량별 가이드를 붙일 수 있으며, 검증되지 않은 실제 브레이킹 지점은 생성하지 않습니다.

기록은 서버로 보내지 않습니다. 실험실은 최근150회/CSV, 실전은100세션·200랩/세션, 코너 노트200개/JSON 내보내기를 지원합니다.

`.openai/hosting.json`은 개인용 Sites 배포 식별자이며 인증정보가 아닙니다. 포크에서 Sites에 배포하려면 자신의 프로젝트 ID를 사용해야 합니다. 저장소 이름에는 작은따옴표가 허용되지 않아 slug는 `INTS-Drive_to_Survive`입니다. 게임 소스·자산·원문 문서는 포함하지 않습니다.
