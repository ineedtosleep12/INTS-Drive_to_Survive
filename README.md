# INTS'Drive_to_Survive

휠 없이 **입력 → 타이어 힘 → 차의 이동과 회전**을 연결하는 한국어 심레이싱 학습 도구입니다. 레이싱을 기반으로 랠리와 드리프트 원리까지 순서대로 다룹니다.

Repository slug: `INTS-Drive_to_Survive` (GitHub 저장소 이름에는 작은따옴표를 사용할 수 없습니다.)

## 실행

별도 라이브러리 설치 없이 `dist/index.html`을 브라우저에서 열 수 있습니다. 패드 인식과 저장 동작은 브라우저에 따라 다를 수 있으므로, 로컬 서버나 HTTPS로 실행하는 방법을 권장합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. Node.js 18 이상이면 설치 단계 없이 실행됩니다.

```sh
npm test
npm run build:offline
```

단일 오프라인 파일은 `build/INTS-Drive_to_Survive.html`에 생성됩니다. 외부 폰트·이미지·패키지·API를 로드하지 않습니다. 소스의 `.openai/hosting.json`은 최초 개인용 Sites 배포 식별자이며 인증정보가 아닙니다. 포크한 프로젝트에서 Sites에 새로 배포하려면 자신의 프로젝트 ID로 교체해야 합니다.

## 포함된 기능

- **거동 실험실**: 90° 코너, 직선 제동, 저접지 슬라럼, 드리프트 입문용 스키드패드.
- **실시간 설명**: 앞뒤 축 힘과 요구/한계, 네 바퀴의 근사 수직하중, 차체 슬립각 β, 타이어 슬립각 α, 요레이트, 방향 화살표.
- **입력**: W/S/A/D 또는 방향키, 마우스 패드와 유지형 슬라이더, 표준 Gamepad 왼쪽 스틱·LT·RT.
- **반복 훈련**: 동일 코너 5회, 진입·회전·탈출 구간 시간, 같은 조건의 이전 최고 기록 대비 차이, 유효율과 표준편차.
- **이론과 판단**: 6개 강의, 실제 예·흔한 오해·실험 절차·자기점검, 8개 상황 문제, 용어와 원문 참고 자료.
- **기록**: 브라우저 localStorage, 최근 150회, CSV 내보내기. 사용자 기록을 서버로 전송하지 않습니다.

Space는 일시정지, R은 재시작입니다. 키보드 조향은 조작 편의를 위해 속도에 따라 최대 입력을 줄입니다. 표시 조향각은 핸들 회전각이 아닌 앞바퀴 각도입니다. 0.5×는 관찰용이며 기록은 시뮬레이션 시간입니다. 탭 이탈·모달 열기·브라우저 포커스 이탈 시 자동으로 일시정지합니다.

## 물리 모델의 느낌과 한계

단순한 평면 비선형 bicycle model입니다. 앞뒤 축을 각각 하나의 대표 타이어로 계산하고 질량 1320 kg, 휠베이스 2.65 m의 교육용 가상 차량을 사용합니다. 슬립각에 따른 횡력, 종횡력 결합 한계, 필터를 적용한 가속도 기반 전후·좌우 하중 이동, 간단한 부하 민감도와 항력을 포함합니다. 적분 간격은 최대 1/240초입니다.

속도가 너무 높으면 조향 요구를 더해도 충분한 회전력을 얻지 못하고, RWD에서 선회 중 큰 구동 요구는 뒤의 횡력 여유를 줄일 수 있습니다. 이는 개념을 관찰하기 위한 반응이며 특정 차의 핸들링을 재현한 결과가 아닙니다.

`utilF`/`utilR`은 **요구량/한계**로 100%를 넘을 수 있습니다. 원 안의 점은 실제 힘을 표시합니다. 마찰원은 간략한 근사이며 실제 타이어의 고정된 원형 한계를 뜻하지 않습니다. 네 바퀴 하중은 독립 4륜 서스펜션 해석 결과가 아닙니다.

ACC, LMU, AMS2, EA WRC, ACR, AC의 물리를 복제하거나 차량별로 보정하지 않았습니다. 타이어 열·압력·마모, 연료, 복잡한 공력, 캠버, 차동장치 세팅, 서스펜션 세부 운동, 요철·점프·노면 변형, 휠스핀 회전수, FFB를 재현하지 않습니다. 제동은 ABS에 가까운 힘 제한을 가정하고 휠 락을 계산하지 않습니다. 자동 전진 구동이며 후진·완전한 스핀·90° 초과 차체 슬립은 범위 밖입니다. 자갈은 낮은 마찰의 근사입니다.

이 도구의 반복 훈련은 실제 롱런의 타이어·연료 관리 평가가 아닙니다. 휠 없는 연습의 실제 랩타임 향상 효과도 아직 검증하지 않았습니다. 완주 기준 중심선은 최적 레이싱 라인이 아닙니다. 짧은 코너 시간 비교가 실제 게임 텔레메트리 분석을 대체하지 않습니다.

## 추천 학습 순서

1. 하중·접지와 작은 타이어 슬립각을 이해한다.
2. 조향이 늘 때 브레이크를 어떻게 해제하는지 실험한다.
3. 앞이 밀림/뒤가 흐름을 구분하고 원인 후보 하나를 정한다.
4. 조건을 고정하고 같은 코너를 5회 반복한다.
5. 낮은 접지에서 속도·경로·회전의 관계를 다시 확인한다.
6. 차체 방향과 속도 방향을 구분한 뒤 드리프트의 카운터와 회수 타이밍을 배운다.

한 개념을 읽고 결과를 예측한 뒤, 입력 하나만 바꾸고 반응을 확인하세요. 다음 실제 심 세션에서 익숙한 차·고정 셋업으로 같은 질문 하나를 검증하는 것이 목표입니다.

## 검증 상태

물리 테스트는 38,106개 상태의 유한성, 힘·하중 한계, 좌회전 부호, 제동, 노면 차이, 반복성, 프레임률 간 일관성을 검사합니다. 앱 로직은 가상 DOM에서 구간 측정·완주·5회 제한·세트 보존·일시정지·저장 데이터 검증을 확인했습니다.

실제 브라우저 시각 QA는 실행 환경의 브라우저 연결/URL 확인 문제로 완료하지 못했습니다. 실물 패드와 휠은 검증하지 않았습니다. 단위 검증 통과는 물리가 실제 차량과 일치한다는 검증이 아닙니다.
